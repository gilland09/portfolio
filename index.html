Case study / 01

Altruria: from farm to front door

The problem

Local farm-to-consumer commerce needs a clear, dependable way for customers to discover produce, place orders, and understand fulfillment—while giving administrators practical tools to manage every order.

Technical architecture

Altruria pairs a Django REST Framework API and MySQL database normalized to third normal form with a Vanilla JavaScript storefront. JWT authentication protects account flows; persistent cart behavior, multi-step checkout (GCash, bank transfer, and COD), and admin order lifecycle tracking support the end-to-end experience. WhiteNoise serves static assets in deployment.

  • 13 REST API endpoints
  • MySQL (3NF)
  • JWT authentication
  • Responsive storefront

Results

95.8%Functional test pass rate

95/100Lighthouse score

Lessons learned

Designing the complete order lifecycle made the value of clear state transitions and reliable data relationships tangible. Building with a small, dependency-free frontend also reinforced the importance of accessible native controls, responsive layouts, and deliberate performance choices.
