PulmoCare — Clinical Decision Support System for Pre-Diagnosis of Pulmonary Infections & Patient Appointment Scheduling

A deterministic, knowledge-based Clinical Decision Support System built for Naval Doctors Healthcare Services Inc. It uses text normalization and a multilingual symptom phrase dictionary (English, Tagalog, Cebuano/Bisaya) with negation and typo/fuzzy matching, red-flag triage (URGENT, UNRELATED, VALID), guided follow-up questions, and a Decision Tree-Based Rule Engine with weighted scoring (S = (R / M) × 100; minimum match threshold: 50/100) across Influenza, Pneumonia, Acute Bronchitis, and Tuberculosis. Clinic appointments and teleconsultations are integrated into the workflow.

Evaluation: ISO/IEC 25010 pooled mean 3.94/5.00 (Maintainability 4.08); UTAUT2 pooled mean 4.13/5.00 across 80 respondents (Performance Expectancy 4.33).

Case study / 01

Altruria: from farm to front door

The problem

Local farm-to-consumer commerce needs a clear, dependable way for customers to discover produce, place orders, and understand fulfillment—while giving administrators practical tools to manage every order.

Technical architecture

Altruria uses a decoupled client-server deployment: a static HTML5/CSS3/JavaScript storefront hosted on GitHub Pages communicates through REST endpoints and JWT authentication with a Django REST Framework API and MySQL database hosted on PythonAnywhere. Persistent cart behavior, multi-step checkout (GCash, bank transfer, and COD), and admin order lifecycle tracking support the end-to-end experience.

  • 13 REST API endpoints
  • MySQL (3NF)
  • JWT authentication
  • Responsive storefront

Frontend: GitHub Pages storefront
Backend API: PythonAnywhere API

Results

95.8%Functional test pass rate

95/100Lighthouse score

Lessons learned

Designing the complete order lifecycle made the value of clear state transitions and reliable data relationships tangible. Building with a small, dependency-free frontend also reinforced the importance of accessible native controls, responsive layouts, and deliberate performance choices.
